Contact form API contract (for the backend builder):
- Endpoint: POST /api/appointment
- Content-Type: application/json
- Body shape:
  {
    "name": string,        // required, e.g. "Anitha R."
    "phone": string,       // required, e.g. "+91 98765 43210"
    "email": string,       // optional, may be empty string ""
    "treatment": string,   // optional, one of TREATMENTS[].name or "General consultation", may be empty string ""
    "date": string,        // optional, yyyy-mm-dd (HTML date input format), may be empty string ""
    "message": string      // optional, may be empty string ""
  }
- Expected response: 2xx on success (the frontend doesn't read the body on success — it shows a toast and resets the form); non-2xx on error (the frontend shows an error toast suggesting to call BRAND.phone directly).
